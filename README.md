# 🎮 Ring Craft

Проект создан для удобства игроков. Главный инструмент сайта — **интерактивный калькулятор колец**, который полностью избавляет от необходимости вести сложные подсчеты в уме.

### 🌟 Основные возможности:
* **Калькулятор колец** — больше не нужно высчитывать в уме, сколько ресурсов или колец требуется для крафта.
* **Удобный интерфейс** — простой дизайн, где всё необходимое находится под рукой.
* **Быстрый доступ** — сайт отлично оптимизирован для работы на мобильных телефонах прямо во время игры.
